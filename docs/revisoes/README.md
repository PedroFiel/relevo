# Revisões

Dois tipos de revisão:

1. **Revisão de código (por PR)** — antes de todo merge na `main`. Quem revisa usa o
   [checklist](checklist-revisao.md). Pode ser um colega ou o Claude
   ("revise a branch atual com o checklist de revisão e liste os problemas por gravidade").
   Resultado fica nos comentários do PR.

2. **Revisão de fase** — no fim de cada fase, um arquivo `fase-N.md` a partir do
   [TEMPLATE-fase.md](TEMPLATE-fase.md): o que foi entregue, demo, métricas, o que ficou para trás, decisões, lições.
   É o material que alimenta os slides.

Prints e vídeos curtos vão em `docs/revisoes/assets/`.
